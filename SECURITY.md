# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 2.x     | Yes       |
| < 2.0   | No        |

Security fixes are released for the 2.x line.

## Reporting a Vulnerability

This library lets an LLM call application code, so please report security vulnerabilities privately. Do not open a public issue.

Use GitHub private vulnerability reporting: go to the Security tab of this repository and select Report a vulnerability.

Please include the affected version, steps to reproduce, and the impact.
